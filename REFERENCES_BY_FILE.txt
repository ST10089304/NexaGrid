NEXAGRID SOURCE AND IN-TEXT CITATION GUIDE

Purpose
-------
This file keeps academic references separate from README.md. It does not claim that every source was directly copied into the code. The source keys below identify credible guidance relevant to the design decisions in each file. Add only citations you genuinely relied on, using the citation style required by your institution.

Suggested in-code form
----------------------
Use concise comments only where a design choice needs attribution, for example:
// File validation follows allow-list and generated-name guidance (OWASP Foundation, 2026).
Avoid adding ten repetitive comments to every file. The rubric assesses proper referencing, not comment volume.
